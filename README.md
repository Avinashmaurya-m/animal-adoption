# RescueNest

RescueNest is a responsive community app for animal adoption, rescue, lost-and-found posts, and local support.

## Stack

- Static HTML, CSS, and browser modules
- Firebase Authentication and Cloud Firestore
- Firebase Cloud Functions for like counts and notifications
- Cloudinary for public image delivery

## Run locally

Serve this folder with any static web server (not `file://`) and configure Firebase Authentication's authorised domains. For Firebase deployment details, see [FIREBASE_SETUP.md](FIREBASE_SETUP.md).
